# Space Explorers

A friendly trip around the solar system for kids. Fly with Zib the alien, meet the Sun and the eight planets, play quick quizzes and fill your sticker book.

**Live:** https://space.sraas.dev

## Run it

```sh
npm install
npm run dev
```

React and TypeScript, all in the browser. `./deploy.sh` publishes the static site to the VPS.
